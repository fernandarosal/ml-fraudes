# ml-fraudes
Este repositório é baseado na publicação do modelo de detecção de fraudes do Nerd dos Dados. A partir desse trabalho, expandi a análise adicionando novos modelos de Machine Learning e incluindo métricas adicionais de avaliação, como KS, AUC e Gini, para aprofundar a comparação de performance entre diferentes algoritmos.

📌 Conteúdo

Implementação original do modelo de fraudes.

Inclusão de algoritmos adicionais: Random Forest, Regressão Logística, SVM e KNN.

Avaliação detalhada com métricas de classificação e separação (KS, AUC, Gini, matriz de confusão).

Scripts organizados para facilitar a reprodução e estudo.

🎯 Objetivo

Explorar diferentes abordagens de Machine Learning aplicadas à detecção de fraudes, comparando resultados e mostrando como métricas específicas podem ajudar na escolha do modelo mais adequado em cenários reais.


📊 Métricas utilizadas

KS (Kolmogorov-Smirnov): mede a separação entre bons e maus.

AUC (Área sob a curva ROC): avalia a capacidade de discriminação.

Gini: derivado do AUC, muito usado em relatórios de crédito.

Matriz de confusão: mostra acertos e erros em cada classe.

📈 Resultados

Os resultados incluem comparações entre diferentes modelos, destacando pontos fortes e fracos de cada abordagem.

🤝 Créditos

Projeto inspirado no trabalho do Nerd dos Dados, com extensões e melhorias próprias para fins de estudo e prática.
